02Guide

From first line to the corners

Each snippet runs in a project that has only this package added.

1

Parse and read a reference

A reference is five components. Read it, then ask for any of them.

Decode & read
let url = @moonurl.Url::decode("https://leo:pw@example.test:8443/a/b?x=1#top")
url.scheme      // Some("https")
url.host        // Some("example.test")
url.port        // Some(8443)
url.query       // Some("x=1")
url.origin()    // "https://example.test:8443"
2

Resolve a relative reference

resolve applies RFC 3986 §5.4 against a base.

Resolve
let base = @moonurl.Url::decode("http://example.test/a/b/c")
base.resolve(@moonurl.Url::decode("../d"))
// http://example.test/a/d
3

Two readings of the same string

syntax defaults to rfc3986, so existing code is unchanged. The WHATWG reading normalises on the way in.

Two grammars
@moonurl.Url::decode("HTTP://EXAMPLE.test:80/a/../b").encode()
// "HTTP://EXAMPLE.test:80/a/../b"

@moonurl.Url::decode("HTTP://EXAMPLE.test:80/a/../b", syntax=@moonurl.Whatwg).encode()
// "http://example.test/b"
4

Names in any script

A host name goes through UTS 46; an ASCII name is taken as it stands.

Internationalised host
@moonurl.domain("MÜNCHEN.example")                        // "xn--mnchen-3ya.example"
@moonurl.Url::decode("http://192.0x00A80001/", syntax=@moonurl.Whatwg).host
// Some("192.168.0.1")
5

Fill in a template, read it back

All four levels; capture reverses expand.

Templates
let values : Map[String, @template.Value] = Map([])
values.set("id", @template.Value::Text("42"))
values.set("page", @template.Value::Text("2"))

@template.Template::decode("/users/{id}{?page}").expand(values)
// "/users/42?page=2"
@template.Template::decode("/users/{id}{?page}").capture("/users/42?page=2")
// [("id", "42"), ("page", "2")]
6

Form bodies and data URLs

A URL's query and a form body are the same ordered pairs.

Forms & data URLs
let q = @moonurl.Query::decode("a=1&b=2&a=3")
q.get("a")        // Some("1")
q.values("a")     // ["1", "3"]
q.encode()        // "a=1&a=3&b=2"

@moonurl.dataurl.Url::decode("data:text/plain,Hi%20there").data
// b"Hi there"
